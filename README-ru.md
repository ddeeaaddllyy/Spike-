# Спайк

[English](README.md) · [Русский](README-ru.md) · [Deutsch](README-de.md)

Нажми **PWR** — на каменной террасе у озера появится Спайк. Коснись его, и он подпрыгнет от радости. Задержи палец — замурчит. Путешественник в сливовом плаще стал маскотом проекта. На том же круглом экране живёт карта с математическими шпаргалками для 10 и 11 классов.

## Управление

| Действие | Что произойдёт |
| --- | --- |
| Нажать PWR | Открывается сцена со Спайком. Свайп вбок отправляет его гулять, вверх — прыгать, вниз — спать. Повторное нажатие возвращает приветствие. |
| Нажать и отпустить BOOT | Открываются настройки. Выбери **30**, **60** или **120** секунд до отключения экрана. Выбор действует до перезагрузки, исходное значение — 60 секунд. |
| Удерживать BOOT 0,9 секунды | Открывается карта. Двигай её вбок, чтобы найти другие темы. Проведи вверх, чтобы перейти от 11 класса к 10-му. |
| Коснуться темы | Открывается шпаргалка. Кнопка **«К карте»** возвращает на прежнее место. |
| Нажать любую кнопку при погашенном экране | Появляется прежний экран. Следующее нажатие работает как обычно. |

На карте 14 карточек по материалам МЦКО для 10 класса за 2026 год и для 11 класса за 2023 год. Начни с «Производной» и сдвинь карту до соседней ветки «Функции». [Описание для 10 класса](https://100ballnik.com/wp-content/uploads/2026/04/opisanie_ma_10_profil_mcko2026.pdf) · [Описание для 11 класса](https://100ballnik.com/wp-content/uploads/2023/09/mcko_2023_mat_11klass_variant.pdf)

## Сборка и прошивка

Понадобится **Waveshare ESP32-S3-Touch-AMOLED-1.32** и USB-кабель с передачей данных. Установи Rust для Xtensa с именем инструментария `esp` и утилиту `espflash`. В CI используются версии 1.97.0.0 и 4.7.0 соответственно. Запускай команды из корня проекта. Вторая записывает прошивку на плату и открывает последовательный монитор. [espup](https://github.com/esp-rs/espup) · [espflash](https://github.com/esp-rs/espflash)

**Русская прошивка (по умолчанию)**

```sh
cargo build --release --locked
cargo run --release --locked
```

**Английская прошивка**

```sh
cargo build --release --locked --features english
cargo run --release --locked --features english
```

Каждый образ содержит один комплект надписей и один шрифт интерфейса. Стартовое приветствие `hello everynwan` общее. Чтобы сменить язык интерфейса, запиши другой образ. На немецкий переведена документация.

## Как устроен круглый экран

![Восемь поз Спайка из прошивки](assets/spike-poses.png)

Экран 466 × 466 пикселей отрисовывается полосами по четыре строки через буфер DMA на 3840 байт. При сборке восемь поз Спайка упаковываются в 4-битную палитру, а фон озера — в серии пикселей RGB565. Плата читает их из flash. При анимации обновляется только область сцены с персонажем.

Графика лежит в [assets](assets), переводы надписей и карточек — в [src/lang](src/lang), распознавание жестов — в [src/gestures.rs](src/gestures.rs). Локальные проверки описаны в [руководстве участника](AGENTS.md). Для тега `v*` на коммите из истории `main` собираются два образа релиза, `spike-esp32s3.bin` (RU) и `spike-esp32s3-en.bin` (EN), каждый со своей контрольной суммой SHA-256. [Конфигурация релиза](.github/workflows/firmware.yml)
